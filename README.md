### Sobre o projeto

O AgriFarm é uma plataforma de gerenciamento inteligente voltada à administração de propriedades rurais, desenvolvida para centralizar informações e otimizar o controle da alimentação animal.

O sistema integra gerenciamento de fazendas, lotes, cochos, rações, estoque, planos alimentares e indicadores operacionais, utilizando tecnologia e análise de dados para auxiliar produtores rurais na tomada de decisões.

| PHP 8+ | Lógica de negócio |
| Laravel 12 | Framework back-end |

- Reduzir desperdícios de alimentação.
- Melhorar o controle de estoque.
- Centralizar informações da propriedade rural.
- Facilitar o acompanhamento dos lotes.
- Apoiar decisões baseadas em dados.
- Integrar tecnologia à gestão rural.
- Promover eficiência e sustentabilidade.
